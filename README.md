# LST-AI Code Review Agent

## Gereksinimler

- Python 3.11+
- Node.js 18+

---

## Backend (API Sunucusu)

```bash
cd api
pip install -r requirements.txt
python main.py
```

API `http://localhost:8000` adresinde çalışır.

---

## Frontend

```bash
npm install
npm run dev
```

Frontend `http://localhost:5173` adresinde çalışır.

> Frontend'in çalışması için API sunucusunun açık olması gerekir.
